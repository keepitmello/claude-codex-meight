# Consult Question

코딩 에이전트로 **작업을 위임할 때**, 작업 종류별로 GPT-5.6 (sol / Pro 계열), Claude Opus 5, Claude Fable 5 중 어느 쪽이 실측 벤치마크에서 앞서는가?

## 배경 (왜 묻는가)

로컬 오케스트레이터(Claude Code)가 워크스트림을 세 갈래로 위임한다:

1. Claude subagent — Opus 5 기본, 판단이 무거우면 Fable 5
2. Codex 워커 — GPT-5.6 계열 (내부 별칭 sol / luna), CLI 하네스 경유
3. ChatGPT Pro consult — 지금 이 대화

현재 라우팅 문서에 적힌 기준은 이렇다:

> Codex와 Claude는 영역이 아니라 경향이다. Codex는 집요하고 엄밀해서 백엔드 로직·데이터 경로·디버깅 그라인드에서 값을 하고, Claude는 UX를 읽어서 화면·플로우·카피·인터페이스 설계에서 값을 한다.

이 서술의 근거가 통념과 개인 경험뿐이라 약하다. 특히 "Claude에게 백엔드를 맡길 일도 많은데 이 경계가 애매하다"는 문제의식이 있다. 공개 벤치마크로 교정하고 싶다.

## 원하는 출력

작업 종류별 표. 각 행에 다음을 넣어달라:

1. 해당 축을 재는 벤치마크 이름과 **최신 수치** (모델별)
2. **출처** — URL과 발표/측정 일자
3. 그 벤치마크가 실제 위임 작업을 얼마나 대표하는지에 대한 당신의 평가 (대표성이 낮으면 낮다고)

작업 종류:

1. 백엔드 로직·알고리즘 구현
2. 버그 수정 / 리포지토리 단위 문제 해결 (SWE-bench Verified 계열)
3. 긴 에이전틱 실행 — 다단계 도구 사용, 장시간 자율성, 터미널 작업 (Terminal-Bench 계열)
4. 프론트엔드 구현 — 실제 동작하는 React/Next 등의 UI
5. UX·비주얼 디자인 판단 — 사람 선호 기반 (WebDev Arena, Design Arena 등)
6. 대규모 리팩터 / 크로스커팅 변경
7. 테스트 작성과 검증
8. 리서치·문서 종합

## 특별히 답해줬으면 하는 것

- "Claude가 UX·프론트엔드에서 앞선다"는 통념이 **현재 세대**(GPT-5.6 vs Opus 5 / Fable 5)에서도 실측으로 유지되는가? 뒤집혔거나 격차가 사라진 축이 있나?
- "백엔드·디버깅은 GPT-5.6이 앞선다"는 통념은 실측으로 유지되는가?
- 벤치마크가 아예 없거나 신뢰하기 어려운 축은 명시해달라. 그 축에서는 무엇을 대리 지표로 삼을 수 있나?
- Fable 5와 Opus 5의 차이가 유의미하게 벌어지는 작업 종류는 무엇인가? (Fable 5는 비용이 훨씬 비싸서, 값을 하는 자리를 알고 싶다)
- 위 8개 분류 자체가 위임 라우팅 기준으로 적절한가? 더 나은 분류 축이 있으면 제안해달라.

## 제약

- 추측과 실측을 명확히 구분해달라. 수치는 출처 없이 쓰지 말 것.
- 모델명이 헷갈릴 수 있으니, 어떤 모델 버전을 기준으로 답하는지 각 표에 명시해달라. 2026년 7월 기준 최신 정보를 원한다.
- 벤더 자체 발표 수치와 독립 평가를 구분해서 표시해달라.

답변은 한국어로 작성해 주세요. 기술 용어와 고유명사, 인용한 논문·제품·API·벤치마크 이름은 원문(영어) 그대로 두고, 설명과 논증만 한국어로 써 주세요.
